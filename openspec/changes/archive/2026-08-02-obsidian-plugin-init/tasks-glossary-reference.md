# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Book Annotation | `glossary/business.md` | Identifies normalized highlight and comment records used by the import core. |
| Managed Book Note | `glossary/business.md` | Identifies the destination note created or safely refreshed by the note service. |
| Provider Adapter | `glossary/technical.md` | Identifies the Yandex integration and future compiled-in provider integrations. |
| Managed Section | `glossary/technical.md` | Identifies the versioned, marker-delimited note region replaced during re-import. |
| Provider Credential | `glossary/technical.md` | Identifies authentication material handled only through SecretStorage and provider calls. |
| Provider Registry | `glossary/technical.md` | Identifies the immutable startup collection used by settings and imports. |
| Import Snapshot | `glossary/technical.md` | Identifies the complete normalized input validated before rendering and writing. |
