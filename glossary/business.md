| Term | Definition | Use When | Avoid |
| --- | --- | --- | --- |
| Reading Provider | An external reading platform from which a user can import books and annotations. | Referring to a selectable source platform such as Yandex Books or LitRes. | Adapter, when referring to the platform rather than its integration code. |
| Book Annotation | A provider record containing highlighted text, an attached user comment, or both. | Referring collectively to imported highlights and provider comments. | Note, which is ambiguous with an Obsidian note. |
| Managed Book Note | An Obsidian Markdown note associated with one provider and book identity and containing replaceable imported content. | Referring to the complete destination note and its re-import behavior. | Managed Section, which refers only to the replaceable region. |
